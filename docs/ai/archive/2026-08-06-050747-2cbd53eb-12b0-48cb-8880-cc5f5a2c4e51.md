ác dự án tham khảo trong thư mục references/ đã triển khai Sandbox Manager cực kì đồ sộ và chuyên sâu. Thực tế, Sandbox Manager là trái tim của các hệ thống AI Coding hiện đại để đảm bảo an toàn (Security) và cách ly môi trường (Isolation).

Dưới đây là các dự án đã triển khai Sandbox Manager và cách họ làm:

1. Project openclaw (Nổi bật và đồ sộ nhất)
Hệ thống này có hẳn một module quản lý Sandbox khổng lồ với các tính năng:

Quản lý Vòng đời (Lifecycle): Có hẳn sandbox-exec-server để giao tiếp JSON-RPC với container.
Cách ly mạng & File System (Filesystem Bridge): Tính năng host-sandbox-fs-bridge giúp mount code an toàn từ máy Host vào Sandbox mà AI không thể vô tình xóa nhầm file hệ thống.
Hỗ trợ Đa môi trường (Multi-agent Sandbox): Mở sẵn môi trường cho trình duyệt (sandbox-browser-setup.sh để AI chạy E2E Test bằng Playwright) và các script JIT (sandbox-setup.sh).
Phân quyền (Policy): Có module validate-sandbox-security.ts và sandbox-tool-policy.ts để chặn các lệnh bash nguy hiểm (như rm -rf / hay trích xuất biến môi trường nhạy cảm).
2. Project ai-sdlc
Họ thiết kế Sandbox Manager theo hướng Interface/Driver Abstraction (chuẩn mực thiết kế phần mềm), cho phép cắm nhiều loại môi trường khác nhau:

Dùng docker-sandbox.ts cho môi trường Local Docker.
Dùng github-sandbox.ts để kết nối trực tiếp với Github Codespaces.
Dùng openshell-sandbox.ts cho các môi trường remote chuyên biệt (như NVIDIA OpenShell). Họ có hẳn một tài liệu RFC thiết kế rõ ràng về cấp phát tài nguyên (Resource limits) cho Sandbox.
